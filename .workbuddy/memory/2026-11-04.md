## 青丘湖硅基工坊（原「办公工具」）— PRD 与 M1 交付

**产品**：青丘湖硅基工坊（Qingqiu Silicon Forge），内部标识 `qingqiu-silicon-forge`。
公司内部 Windows 桌面工具，本地处理文件，AI 可调度但仅连内网/本机模型。

**技术栈**：Tauri 2.12 + Rust 1.99 + React 18 + Vite 6 + TypeScript；Office sidecar 计划用 C#/.NET 10（**不能用 .NET 8，2026-11-10 已 EOL**）。

**文档**：`PRD-青丘湖硅基工坊.md`（v0.6，11 章）。三轮讨论定稿：从「Rust 写转换引擎」被否 → 双引擎（MS Office COM 优先，WPS 降级，不引入 LibreOffice）→ 排期分 Committed(M1-M4) / Conditional(M5-M7，卡内网模型) / Deferred(PDF→Office)。

## M1 已交付（2026-11-04）

代码在 `app/`，20 项测试全绿，`pnpm tauri dev` 可跑。

- **托盘常驻**：关闭入托盘、双击唤出、右键菜单、退出必须确认（有任务时「最小化并继续」为首选按钮）。原则：摩擦只在退出，绝不在最小化。
- **Excel 拆表**：`umya-spreadsheet`，复制-删表-另存策略保样式；跨表引用纯文本解析（支持 `Sheet2!A1`、`'My Sheet'!A1`、`Sheet1:Sheet3!A1`、中文表名，跳过字符串字面量里的 `!`）；三策略 Keep/ToValue/Abort；读一次 Clone 派生避免重复解析。
- **图片转换**：`image` + `resvg` + `kamadak-exif`；PNG→JPG 必须铺底否则变黑；SVG 按目标尺寸渲染；ICO 限 256px；WebP 当前**无损**（质量参数不生效）。
- **设置页**：关闭行为、开机自启（HKCU Run 键，路径含空格须加引号）、功能状态、关于。
- **features.toml 机制**：功能状态单一数据源，`build.rs` 编译期生成静态表。字段 `status` + `delivered` 共同决定 UI（未交付→占位角标，已交付→真入口）。禁用 `todo!()`，用 `FeatureError::NotPlanned`。

## 踩过的坑（复用价值高）

1. **rustc 编译 window-vibrancy 崩溃 0xc0000005** → 并行编译 + debuginfo=2 内存耗尽。解法：`Cargo.toml` 设 `[profile.dev] debug = 1`。
2. **pnpm 12 拦截 esbuild 构建脚本** → `pnpm approve-builds --all` 显式批准一次（`pnpm-workspace.yaml` 的 onlyBuiltDependencies 单独配置不够）。
3. **Tauri 窗口无法截图** → 用系统 Edge `--headless=new --screenshot` 打 vite dev server 验证 UI；为此在 `import.meta.env.DEV` 下加了降级数据和 `?view=` / `?demo=` 参数。
4. **umya-spreadsheet 2.3.3 API**：`new_sheet` 返回 `Result`；`Spreadsheet` 实现了 `Clone`（拆分复用的关键）；`Chart` 不暴露 Series formula，所以图表跨表检测做不到。
